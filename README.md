# ShopSphere AI 🛍️

### Smart E-Commerce Management System Using C++

ShopSphere AI is a console-based e-commerce management system developed using C++ and Object-Oriented Programming (OOP). It demonstrates product management, shopping cart operations, checkout, inventory tracking, and rule-based product recommendations.

## Features

* Product catalog with prices and stock availability
* Shopping cart management
* Product-specific discounts
* Checkout and order recording
* Inventory persistence using file handling
* Sales and inventory analytics
* Rule-based product recommendations
* Input validation and exception handling

## OOP Concepts Used

* Classes and Objects
* Encapsulation
* Abstraction
* Inheritance
* Runtime Polymorphism
* Constructors
* Function Overloading
* Exception Handling

## Technologies

* C++
* STL (`vector`, `map`)
* File Handling
* Object-Oriented Programming

## How to Run

### 1. Compile

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o ShopSphereAI.exe
```

### 2. Execute

On Windows PowerShell:

```powershell
.\ShopSphereAI.exe
```

## Project Limitation

The product recommendations are rule-based and use customer category preferences. The current project does not implement a machine-learning model.
